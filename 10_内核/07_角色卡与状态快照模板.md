# 角色卡 · 状态快照 · 文风锚（三份模板）

> **为什么单独成文件**：这三样是**作家人格开工前必须拿到**的输入。缺任何一样，Author 都会报缺停笔——而在这份文件出现之前，交付集里**没有任何地方说明它们长什么样、从哪里来**。这是交付集的自包含缺口，本文件补上。
>
> **三者的关系**：角色卡管"人不会变的东西"，状态快照管"这一章变了什么"，文风锚管"用什么腔调写"。

---

## 一、角色卡模板（每个主要角色一份）

> 存放：`02_人物\角色卡\{{角色名}}.md`
> **判据**：一张卡合格的标准是——**能回答"他绝对不会做什么"**。答不出就是废卡。

```markdown
# {{角色名}}

- 身份/年龄/职业：
- 与主角关系：
- **首次出场章号**：第 {{NNN}} 章
- 一句话定位：（例：靠规则漏洞活着的老手，不信任任何人）

## 五维

### 1. 核心价值观
写成一个比较句：**{{A}} 比 {{B}} 更重要，可以 {{牺牲什么}}，绝不 {{放弃什么}}**。
（例：活着比面子重要，可以低头认错，绝不扔下同伴）

### 2. 行为红线（3–5 条 · 这是防崩坏的保险丝）
- 绝对不会：____
- 绝对不会：____
- 绝对不会：____
> 写不出 3 条的，说明你还不了解这个角色。**红线越具体越好**（"绝不原谅背叛者" 优于 "有原则"）。

### 3. 情绪反应模式（压力下的本能反应）
- 被威胁时：
- 被信任的人背叛时：
- 面对比自己强的对手时：
- 独处时的习惯性动作/想法：

### 4. 语言指纹（**Author 写对话时逐句对照**）
| 项 | 内容 |
|---|---|
| 句式特征 | （例：句子短、少用形容词、爱用反问） |
| 口头禅（2–3 个） | （例："行吧。""你要这么想也行。"） |
| 称呼别人的方式 | （例：叫主角全名，从不叫昵称） |
| **绝不说的话** | （例：不说"太好了""谢谢你"这类客气话） |
| 说话时的身体习惯 | （例：说狠话时反而笑） |

> **判据**：把本章所有对话遮住说话人，**能不能靠语言指纹认出谁在说话**？不能，就重写指纹。

### 5. 成长弧线
从 {{起始状态}} 到 {{目标状态}}，路径是：____
> 每卷只推进一小步。**不要写"他从幼稚变得成熟"** —— 那是结论，不是路径。

## 状态快照（每章写完更新）
- 当前所在位置：
- 身上有什么（重要物品/道具）：
- 伤势/消耗：
- 当前目标与待办：
- 与主角的信任度：低 / 中 / 高（上次变更：第 N 章）
```

## 二、状态快照模板（**一章一份，供 H5 使用**）

> **用途**：写正文前交给 Author 的"当前局势切片"。**不给快照，涉及物品交接或伤势的章节必然写崩**（作者只能猜）。
> 存放：`05_台账\连续性台账.md` 的对应章节块，或直接在交接包里内联。

```yaml
状态快照 · 第{{NNN}}章开篇时
物品:
  {{角色A}}: [{{物品1}}, {{物品2}}]        # 只列会在本章被用到的
  {{角色B}}: [{{物品3}}]
位置:
  {{角色A}}: {{具体地点}}
  {{角色B}}: {{具体地点}}
伤势:
  {{角色A}}: {{现状}}（来源：第{{N}}章）
任务进度:
  {{主线1}}: 第{{N}}/{{M}} 步
  {{支线1}}: {{状态}}
未销账伏笔: [{{伏笔1}}（第{{N}}章埋）, {{伏笔2}}]
```

**四条纪律**：
1. **只列本章会被用到的**——把整本书的资产全列出来，等于没列（模型抓不住重点）
2. **数量必须与上一章的可核对**（第 10 章有 3 颗子弹，第 11 章不能凭空 5 颗）
3. **空缺也要写**（`身上：无` 比省略更有信息量——省略会被理解成"没提到"，而不是"没有"）
4. **伏笔必须带埋设章号**，否则无法判断"这条该不该现在收"

## 三、文风锚模板（每本书一份）

> 存放：项目卡 §三 已有一份简版；若要详细，另存 `01_设定\文风锚.md`。
> **来源**：本地风格库总览文件的 §一（题材→风格匹配）、§二（题材→风格速查表）、§三（通用写法 10 条）。

```markdown
# 文风锚 · {{书名}}

## 1. 匹配结果
- 本书题材：{{题材}}（可跨类叠加）
- 命中样本：{{样本名}}（按题材从速查表取）
- **一句话风格签名**：（逐字抄录速查表，不要自己重写）
- 核心风格关键词：（逐字抄录）

## 2. 通用写法（跨题材共享，来自速查表 §三）
逐条抄录 10 条，Author 每章都要满足。

## 3. 详细档案状态
**{{可用 / 缺档}}**
> 若为「缺档」：本字段必须保留"缺档"二字，每次交付开头带一行
> `> 文风锚：仅有速查表签名，详细档案缺档`
> **禁止**根据索引里的书名与题材"自行编一份风格规则"——索引里的书名题材都是真的，编出来的规则看起来完全合理，作者无法察觉。**宁可粗，不可编。**

## 4. 本书的额外文风约束（可选）
- 用户明确要求的调性：（例：现实向、不要爽文腔）
  > 若与速查表的"番茄爽文"默认风格冲突，**以用户意图为准**。
- 已生效的去AI味硬禁规则：（从台账摘录条号，不抄内容）
```

## 附：三份模版的已知边界

1. **本文件不代替风格库**。文风锚的**内容**必须从风格库抄录；本文件只规定**格式与缺档纪律**。
2. **状态快照不是连续性台账**。快照是"开篇时的切片"，台账是"完整的时间线记录"。不要用快照代替台账。
3. **角色卡的红线会随剧情推进增加，但绝不删除**。删掉的线会让前文的行为变得无法解释。
